# User stories
**user stories for the login/registration page:**
1. **Account registration** : As a user, I want to register with my name, username, age, and country so that I can create an account and access the habit tracking features.
2. **Account login** : As a user, I want to log in using my username and password so that I can access my account and track my habits
3. **Error feedback on login** : As a user, I want to receive a message if I enter the wrong username or password so that I know my login attempt was unsuccessful.

**Priority:** [High]
