# User stories
**user stories for the habits page:**
1. **Add a new habit** : As a user, I want to add new habits on the details configuration page so that I can manage and update my habits as needed.
2. **Delete a habit** : As a user, I want to delete existing habits so that I can keep my habits up to date.
3. **Personalize a habit with color** : As a user, I want to assign a specific color to each habit to make it personal to me.

**Priority:** [High]
